# Differentiator

### Triangular Input 
| frequency     | R2 (10k) | C
| ------------- | ------------- | ------------- |
1 - 10khz|100%|100pF
10Hz - 1khz|10%|10nF
5Hz - 10hz|10%|100nF
1Hz - 5hz|10%|1000nF

### Square Input
- Follow the above values.
- If unwanted spikes encountered increase the R2 value. 
- If the wave is distorted, reduce the R2 value.
